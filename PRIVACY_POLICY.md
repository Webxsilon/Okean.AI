# Privacy Policy

**Last updated:** November 2, 2026

## 1. Introduction

Okean.AI is an open-source AI role-playing application built around **User-First** principles.

We believe users should have control over their data, AI models, characters, and interactions with external services.

This Privacy Policy explains how Okean.AI handles information when you use the application.

## 2. Data Collection

Okean.AI does not operate its own user-data collection, advertising, or analytics service.

The application does not require an account or registration to use its core functionality.

Okean.AI does not intentionally collect personal information or transmit user data to its own servers.

However, certain features require communication with external services. These features are described below.

## 3. Local Data Storage

Information created or imported within Okean.AI is stored locally on your device.

This may include:

- Conversations and chat history.
- Characters and their descriptions.
- Custom personas.
- Application settings.
- System prompt configurations.
- Downloaded AI models.
- Generated images.
- Custom background music and other local resources.

Okean.AI does not automatically upload this locally stored information to its own servers.

You are responsible for managing your local files, backups, and device security.

## 4. Third-Party AI Services

Okean.AI supports third-party AI services through API integrations.

When you choose to use an online AI provider, relevant information may be transmitted to that provider.

Depending on the service and your configuration, this may include:

- Conversation messages.
- Character and persona information included in prompts.
- System prompt content.
- Dynamic prompt information.
- Other context required to generate responses.
- API requests and technical metadata.
- API credentials required to authenticate requests.

These requests are handled by the selected third-party provider.

Okean.AI does not control how external providers process, retain, or use information submitted through their APIs.

We recommend reviewing the privacy policies and terms of service of your selected providers before using their services.

## 5. Local AI Engines

Okean.AI supports local AI engines such as Ollama and llama.cpp.

When using a locally running model, AI inference takes place on your device.

Conversation content does not need to be sent to an external AI provider for local inference.

However, downloading models, installing dependencies, or using other online features may require an internet connection and communication with external services.

## 6. Image Generation

Okean.AI supports two image generation modes: Cloud and Local.

### 6.1 Cloud Image Generation

Cloud Image Generation allows users to connect supported external image generation APIs.

When using this functionality, relevant information may be transmitted to the selected provider.

Depending on the generation request, this may include:

- Image generation prompts.
- Character descriptions.
- Scene descriptions.
- Reference images, if supported and provided.
- Other information explicitly included in the generation request.
- API credentials and technical request information.

Cloud image generation is processed by the selected external provider.

The provider's own privacy policy, data retention practices, and terms of service apply to information submitted through its API.

Cloud generation may also involve usage fees charged by the provider.

### 6.2 Local Image Generation

Local Image Generation allows users to generate images using models installed on their own devices.

When generation is performed entirely locally, prompts and generated image content do not need to be transmitted to an external image generation provider.

However, downloading models, installing dependencies, or updating local generation software may involve external services.

The privacy practices of those external download sources are outside the control of Okean.AI.

## 7. Model Downloads and External Resources

Okean.AI may allow users to download AI models, dependencies, and other resources from external sources.

These downloads may connect to third-party websites or services.

External services may process technical information associated with the connection, such as IP addresses, download requests, and other network metadata.

Okean.AI does not control the privacy practices of external download providers.

## 8. Data Sharing

Okean.AI does not sell, rent, or share personal information with advertisers or data brokers.

The application does not operate an advertising or user-tracking system.

Information may be transmitted to third-party services when users choose to use features that require external communication, including:

- Online text generation APIs.
- Cloud image generation APIs.
- Model downloads.
- External dependencies and updates.

The information transmitted depends on the selected feature and the user's configuration.

## 9. API Keys and Credentials

Users may provide API keys to connect third-party AI services.

These credentials are used to authenticate requests to the corresponding providers.

Users should protect their API keys and avoid sharing them with other people.

The security of locally stored credentials depends on the application's implementation and the security of the user's device.

Users should review the storage and security behavior of their installed application version before entering sensitive credentials.

## 10. Data Security and User Responsibility

Okean.AI is designed to give users control over their locally stored information.

However, no application or storage method can guarantee absolute security.

Users are responsible for:

- Protecting access to their devices.
- Keeping backups of important data.
- Managing API keys securely.
- Reviewing third-party privacy policies.
- Understanding what information is sent when using cloud services.
- Avoiding the transmission of sensitive information to external providers unless they understand the associated risks.

## 11. Open-Source Transparency

Okean.AI is an open-source project.

Users can inspect the source code to understand how the application works and how it handles information.

We encourage transparency, community contributions, and independent verification.

## 12. Changes to This Policy

This Privacy Policy may be updated as Okean.AI evolves.

Changes will be published in the project's official repository.

The latest version of this document will be available there.

## 13. Contact

For questions, concerns, or suggestions regarding this Privacy Policy, please use the project's official GitHub repository and its available contact channels.
